# 大學活動企劃與執行 LLM Wiki

本 Wiki 整理大學活動企劃與執行相關的校內規章與社團管理資料，供第一次接觸活動企劃的大學生、系學會及社團幹部閱讀參考。各篇資料依來源學校分開整理，不同學校的制度、期限與補助條件不可互相套用；文件所載歷史規定之現行效力，請依各篇標註的限制確認。

## 閱讀入口

請先閱讀 [Wiki 索引](wiki/index.md)，再依主題或來源學校進入個別文件。
